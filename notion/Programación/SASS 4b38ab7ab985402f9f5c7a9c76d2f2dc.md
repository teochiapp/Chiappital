# SASS

Se instala desde el CMD y replica todo el código de SCSS hacia CSS.

SASS is a stylesheet language that’s compiled to CSS. It allows you to use [variables](https://sass-lang.com/documentation/variables), [nested rules](https://sass-lang.com/documentation/style-rules#nesting), [mixins](https://sass-lang.com/documentation/at-rules/mixin), [functions](https://sass-lang.com/documentation/modules), and more, all with a fully CSS-compatible syntax. Sass helps keep large stylesheets well-organized and makes it easy to share design within and across projects.

**Variables**: Permite definir variables para almacenar valores reutilizables, como colores, tamaños de fuente, márgenes, entre otros. Las variables se declaran con el prefijo **$** y se pueden utilizar en diferentes partes del código.

**$base-color:** #c6538c**;**

**$border-dark:** **rgba(**$base-color**,** 0.88**);**

**$font-weights: (**

**“regular”: 400,**

**“bolder”: 700,**

**);**

**.alert {**

**border:** 1px solid **$border-dark;**

**font-weight: map-get($font-weights, $weight-name);**

**}**

**Interpolation**

**@mixin** **corner-icon(**$name**,** $top-or-bottom**,** $left-or-right**)** **{**

**.icon-**#{$name} **{**

**background-image:** **url(**"/icons/#{$name}.svg"**);**

**position:** absolute**;**

#{$top-or-bottom}**:** 0**;**

#{$left-or-right}**:** 0**;**

**}**

**}**

**@include** **corner-icon(**"mail"**,** top**,** left**);**

**Anidamiento**: Permite anidar selectores CSS dentro de otros selectores, lo que facilita la escritura y lectura del código. Esto evita repetir selectores comunes y ayuda a mantener una estructura jerárquica más clara.

**.accordion {**

**max-width:** 600px**;**

**margin:** 4rem auto**;**

**width:** 90%**;**

**font-family:** "Raleway"**,** sans-serif**;**

**background:** #f4f4f4**;**

**&__copy {**

**display:** none**;**

**padding:** 1rem 1.5rem 2rem 1.5rem**;**

**color:** gray**;**

**line-height:** 1.6**;**

**font-size:** 14px**;**

**font-weight:** 500**;**

**&__open {**

**display:** block**;**

**}**

**}**

**}**

**Importación**: Sass permite importar múltiples archivos Sass en uno solo, lo que ayuda a organizar y dividir el código en módulos más pequeños y manejables. Los estilos importados se combinan en un solo archivo CSS al compilar.

- [@import](https://sass-lang.com/documentation/at-rules/import) extends the CSS at-rule to load styles, mixins, functions, and variables from other stylesheets.

**Herencia**: La herencia en Sass permite crear estilos base y luego extenderlos en otros selectores. Esto ayuda a evitar la duplicación de código y a mantener una estructura más modular y mantenible.

- [@extend](https://sass-lang.com/documentation/at-rules/extend) allows selectors to inherit styles from one another.

**Funciones**: Sass proporciona un conjunto de funciones incorporadas que se pueden utilizar para realizar cálculos, manipular cadenas de texto, trabajar con colores, entre otras operaciones. También se pueden definir funciones personalizadas para adaptarse a necesidades específicas.

- [@function](https://sass-lang.com/documentation/at-rules/function) defines custom functions that can be used in [**SassScript expressions**](https://sass-lang.com/documentation/syntax/structure#expressions).

**Mixins**: Los mixins son bloques de código reutilizables que se pueden incluir en diferentes partes del estilo. Pueden aceptar parámetros, lo que permite crear estilos dinámicos y personalizables.

- [@mixin and @include](https://sass-lang.com/documentation/at-rules/mixin) makes it easy to re-use chunks of styles.

**Operaciones matemáticas:** Sass permite realizar operaciones matemáticas directamente en el código, lo que incluye sumas, restas, multiplicaciones y divisiones. Esto es útil para calcular valores dinámicos, como anchos de columnas o márgenes.

**Directivas de control:** Sass incluye directivas de control, como **@if**, **@for**, **@each** y **@while**, que permiten realizar lógica condicional y bucles en el código Sass. Esto brinda flexibilidad para generar estilos dinámicos y automatizados.

- Flow control rules like [@if](https://sass-lang.com/documentation/at-rules/control/if), [@each](https://sass-lang.com/documentation/at-rules/control/each), [@for](https://sass-lang.com/documentation/at-rules/control/for), and [@while](https://sass-lang.com/documentation/at-rules/control/while) control whether or how many times styles are emitted.
