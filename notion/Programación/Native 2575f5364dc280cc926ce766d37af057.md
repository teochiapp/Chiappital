# Native

### Fundamentals

Components:

Text → Replacement for h1, p, etc

View → like a div

TouchableOpacity → Like a React Button but with more customization

TouchableHighlight → Clickable but not visual feedbakc for links or images

ActivityIndicator → For a Spinner

FlatList → Long lists of items that need to be scrolled

Map function → For smaller lists

SafeAreaView → AppsSupported in different devices, when something is too large

Image → Same as React but to do a background need to use <ImageBackground>

Modal

Alert 

Switch → Toggle items
