### Containers:

Containers are used to contain, pad, and align content.
The container class uses max-width breakpoints
container-sm container-md container-lg container-xl container-xxl
Fluid Container:
The standard container snaps to pre-set pixel widths based on the size of the browser.

### Bootstrap Grid System:

Are limited to twelve columns.
To create a row, we use the class row, and place it inside the class container
To add a breakpoint to a column, simply use the
class col-* where the asterisk can be replaced with xxl, xl, lg, md and sm.
To assign a width to a column, we use col-*
where the asterisk can be replaced with any value between one and twelve.

Images: class=" w-100 w-75 w-50 w-25 img-fluid img-thumbnail float-start float-end"

Cards: divided by Card Header Card Body Card Footer

Gutters
Represent the spacing between your columns.
They are used to space and align content in the Bootstrap grid system.
