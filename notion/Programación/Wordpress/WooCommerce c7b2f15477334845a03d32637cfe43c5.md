# WooCommerce

### PRODUCTOS

Titulo, precio, Sku, descripcion, stock, img destacada, categorías y etiquetas (SEO)
-se puede agregar stock por lista de excel
-CATEGORIAS, subcategorias -> agrupan productos, tienen jerarquia. Ejemplo: MUEBLES - mesa
-ETIQUETAS -> definen los productos, abarcan las busquedas para el producto
-PRODUCTOS RELACIONADOS -> se muestran segun las categorias y etiquetas en comun
-PRECIO -> puede configurarse por fecha, rebajas en el precio del producto
-SKU -> codigo del producto, permite controlar el inventario y dar aviso de falta de stock
-ENVIOS -> se detalla el peso, dimensiones
-VTAS CRUZADAS -> Se sugieren productos complementarios al producto seleccionado para la compra
-PRODUCTOS AGRUPADOS -> se configuran los productos relacionados al seleccionado
-PRODUCTOS EXTERNOS -> vtas dirigidas a pags externas
-ATRIBUTOS -> variaciones del producto, talles, colores, etc. Pueden insertarse mas img segun el atributo
-PRODUCTOS VIRTUALES -> no se envian, suelen usarse para servicios
-PRODUCTOS DESCARGABLES (digitales)-> se configura como el usuario accede al producto de descarga. Ejemplo: steam -> juego
usar 1 y 2 metodo, que tienen proteccion del archivo, no permite compartir la url de descarga del archivo

### [**Examples of Product Scenarios**](https://woocommerce.com/document/woocommerce-shortcodes/#examples-of-product-scenarios)

### **Scenario 1 – Random Sale Items**

I want to display four random on sale products.

```
[products limit="4" columns="4" orderby="popularity" class="quick-sale" on_sale="true" ]
```

### **Scenario 2 – Featured Products**

I want to display my featured products, two per row, with a maximum of four items.

```
[products limit="4" columns="2" visibility="featured" ]
```

This shortcode says up to four products will load in two columns, and that they must be featured. Although not explicitly stated, it uses the defaults such as sorting by title (A to Z).

### **Scenario 3 – Best Selling Products**

I want to display my three top best selling products in one row.

```
[products limit="3" columns="3" best_selling="true" ]
```

### **Scenario 4 – Newest Products**

I want to display the newest products first – four products across one row. To accomplish this, we’ll use the Post ID (which is generated when the product page is created), along with the order and orderby command. Since you can’t see the Post ID from the frontend, the ID#s have been superimposed over the images.

```
[products limit="4" columns="4" orderby="id" order="DESC" visibility="visible"]
```

### **Scenario 5 – Specific Categories**

I only want to display hoodies and shirts, but not accessories. I’ll use two rows of four.

```
[products limit="8" columns="4" category="hoodies, tshirts" cat_operator="AND"]
```
