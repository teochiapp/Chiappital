**Wordpress** es un software de código abierto para web apps que permite administrar información sin necesidad de escribir código HTML, CSS, Javascript.

Requiere saber PHP, MySql, HTML, CSS, Javascript.

**Templates**: Mayor tiempo vigente. Utiliza archivos para que Wordpress los use como archivos propios

**Gutenberg**: Crear tus propios bloques con React.

**Headless**: Buena opción para código de React pero no quieren Gutenberg.

### **Creando sitio WEB Gimnasio (Notas)**

**Have__post** consulta la base de datos, post es la palabra genérica.

Para poder agregar **styles** y encolar archivos de **Javascript** tenemos que agregarlo a functions.

Cuando se usan las funciones get (header,field, title) busca datos de wordpress y se le pueden agregar los atributos entre comillas.

**Functions** es el archivo en el cual vamos descubriendo cierta funcionalidad de Wordpress.

Los **Post Types** almacenan diferentes tipos de contenidos en la base de datos. Crean las secciones extra de Wordpress.

Un **tema** es para la presentación y el diseño de  tu sitio web. Si el tema requiere ciertas funciones, utiliza el functions.php

Un **plugin** es para funciones en general que no dependan del tema que tengamos activados.

**Tema** para **diseño**, **plugin** para **funcionalidad**.

**ACField** se usa para agregar campos personalizados a nuestras clases.

Para poder crear **widgets**, debemos definir una zona de widgets. Esta usa un template definida para adaptar el código.

**Lightbox** es un script para mejorar el manejo de imágenes.

En wordpress se usan mucho los plugins para facilitar el proceso y solo debemos agregar un poco de código.

**Contact Form** para el formulario de Contacto.

**Shortcodes “**are snippets of code can be inserted just about anywhere to add dynamic features”. Se ponen dentro del formulario en Wordpress y accede a otro código mas largo y complejo.

En nuestro código se usa como do_shortcode(“[]”).

**Sendinblue** permite hosting para emails.

**Swiper** es un plugin que se usa para que se muevan citas con autoplay.

**Moving letters** agrega animación a textos.

**Tabler Icons** nos da iconos para tu pagina.

La regla de CSS **@media** asocia un grupo de declaraciones anidadas, en un bloque CSS delimitado por llaves, con una condición definida por un media query.

**Comment_form()** nos renderiza una sección de comentarios.

Para paginar podemos usar simplemente **posts_nav_link()** para usar el “pagina siguiente o **the_posts_pagination()** para el de números.

Para mejorar el performance podemos agregar ifs en los scripts para que los plugins aparezcan solo donde son necesarios. También podemos usar plugins de caché.
