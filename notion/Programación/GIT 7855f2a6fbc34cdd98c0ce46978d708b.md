# GIT

### USOS DE GIT:

- Historial 

- Almacenar código 

- Trabajar en equipo 

- Saber cuando se introdujo un error en la app (Rollback)

### GIT CHEATSHEET: [https://education.github.com/git-cheat-sheet-education.pdf](https://education.github.com/git-cheat-sheet-education.pdf)

### Configuraciones para determinar usuario:

git config –global user.name “Teo Chiappero” 

git config –global user.email “teochiapps@gmail.com”

### Ver configuraciones:

git config –global core.editor “code –wait”

 git config –global -e (Se abre dentro de VSCode)

git config –global core.crlf true git config -h (Ver todas las configuraciones de Git)

### Comandos básicos de BASH:

ls (Listar todos los archivos y carpetas de determinado directorio) 

pwd (En que carpeta nos encontramos) 

cd directorioAlQueNosDirigimos mkdir nombre(Crear directorio)

git init (Inicializar repositorio vacío en el cd) ls -a (Mostrar todos los archivos incluso ocultos)

cd.git (Ingresar carpeta de GIT) Al hacer ls -a: Aparece el detalle de IMPLEMENTACIÓN HEAD config description hooks info objects refs

cd .. (Volver atrás)

### Flujo de trabajo con GIT

Computador > Stage > Commit > Server

### Agregando cambios a Stage:

git status (Ver estado del repositorio) 

git add “nombreArchivo”

Cuando cambiamos algo en el archivo y ponemos git status nos dirá que hubo cambios

git commit -m “nombre” git commit

rm “nombreArchivo” (Para eliminar archivos) 

o mas rápido: git rm “nombreArchivo”

Para recuperar un archivo usamos: git restore –staged nombreArchivo git restore nombreArchivo

Para cambiar nombre archivos: mv archivo1 archivo.txt

Para ignorar archivos o repositorios: Crear un .gitignore

un git status mejor o más limpio: git status -s

### Visualizar los cambios realizados todavía no pasados a stage:

git diff 

git diff –stage (cambios en etapa de stage)

### Comando para ver el historial:

git log (Mostrar todo)

 git log –oneline (Muestra el historial con un hash identificador)

### Ramas o branches en GIT:

git branch (Nos muestra en que rama estamos trabajando) 

git checkout -b ramab (Crear nueva rama)

Mostrar contenido de un archivo: cat nombreArchivo

Traer cambios de una rama a main: git merge nombreRama (Desde main)

### Subir a GitHub:

git remote add origin “urlGit.git” git push -u origin main

### Para actualizar un código:

git add 

git commit 

git push
